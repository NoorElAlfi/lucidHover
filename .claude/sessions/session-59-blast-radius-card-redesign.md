## Decisions made
- **Generalized `.lh-back` for the graph view's "← Back" control** rather than adding a near-identical sibling class — both are the same "breadcrumb above the card, not a card action" affordance `.lh-back`'s own doc comment already describes (used in `renderExplanation`'s "Back to caller" link). Judged unambiguous enough not to need `AskUserQuestion`; `code-reviewer` independently confirmed no semantic mismatch.
- **New `.lh-graph-*` classes are standalone, not built on `.lh-refs`/`.lh-ref-row`'s selectors**, even though the task described the target look as "an `.lh-refs`/`.lh-ref-row`-style row." Those existing selectors are scoped to a `.lh-refs` ancestor; `renderGraphNode()` is shared with `renderBranchPoint()` (execution trace's branch-alternate expander), whose `<details>` container is not a `.lh-refs` ancestor. Coupling the look to that ancestor selector would have left branch-alternate rows unstyled — an out-of-scope regression. Standalone classes achieve the identical visual look without that dependency.
- **Restyling `renderGraphNode`/`addBackLink` was allowed to visually uplift execution trace's node/back-link rendering too**, since both helpers are shared and the session brief named `renderGraphNode` itself as in-scope. `renderTrace`/`renderBranchPoint`'s own layout logic (the "↓ calls" arrows, the `<details>`/`<summary>` expander) was not touched.
- **Omission notes reuse the plain `.empty-state` class** (with a `.lh-section .empty-state` margin tightener), matching the "Not yet indexed." treatment already used for uncached nodes, rather than inventing a new empty-state variant.
- Removed `addSection()` (dead after this session's edit removed its only call site) — not asked for explicitly, but leaving a function with zero callers behind from this session's own edit didn't fit the project's "no half-finished implementations" norm. Two other pre-existing dead helpers (`addNameLinks`, `addList`) were left alone — they were already unused before this session, unrelated to this change, out of scope.
